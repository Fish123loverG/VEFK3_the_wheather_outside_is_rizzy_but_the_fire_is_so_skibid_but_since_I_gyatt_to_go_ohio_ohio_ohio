## Functional requirements

Fr-01: Search function that finds what the search is displayed.
Fr-02: Account with a basic username, password and email requirement.
Fr-03: A way to publishers and developers to communicate with each other(with the function to send images and texts.
Fr-04: Profiles with a role that is either a publisher or a developer and can have a basic text description.
Fr-05: A page that has an overview of all the developers who are looking for a publisher(bulletin board style).

## Non-functional requirements

NFR-01: Able to notify developer whenever publisher sent a message in the website.
NFR-02: Have the massages be immediately encrypted for safety.
NFR-03: Have data requirements for posting to the bulletin board.

## User stories
US-01: As a developer, I want to contact publisher so that I can get a publishing deal.
    PASS/FAIL: Only developers should be able to message publishers.
